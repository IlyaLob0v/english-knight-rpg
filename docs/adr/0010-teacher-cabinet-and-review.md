# ADR 0010. Кабинет преподавателя и проверка файлов

Статус: принято · 2026-10-28

## Контекст
Неделя 6 плана: преподаватель видит, кто занимался и в какие дни, точность и частые ошибки, проверяет сданные файлы (оценка и комментарий видны ученику), а еженедельный отчёт по ученику собирается сам.

## Решение
- **Журнал ответов на шлюзе.** Каждый `answered` из приёма xAPI разбирается обратно в попытку (`attemptOf` в `@moonbridge/xapi`) и пишется в таблицу `attempts` (`migrations/003_review.sql`). Ключ — id statement'а, поэтому повторная отправка из офлайн-очереди ничего не удваивает. Сбой записи в журнал не мешает доставке в LRS.
- **Кабинет считает из своей таблицы, а не из LRS.** Отчёт за неделю — несколько агрегатов по индексу `(player_id, answered_at)`; LRS остаётся источником для аналитики пилота и выгрузок.
- **Неделя — с понедельника по воскресенье по Москве**, дни практики — московские даты с хотя бы одним ответом.
- **Точность — по первым попыткам.** Повторная попытка после подсказки говорит больше о подсказке, чем о знании.
- **Частые ошибки** — типы из таксономии с русскими названиями из живого контента; ответ, который автор не предусмотрел, считается `unclassified`.
- **Оценка 1–5 и комментарий** хранятся в `submissions`. Новая загрузка того же задания стирает оценку и возвращает файл в очередь: новый файл проверяется заново.
- **Записи и фото открываются в кабинете** по той же ссылке на 5 минут, что и скачивание.
- **Сброс пароля — у преподавателя ученика.** Шлюз генерирует пароль из 10 символов без похожих букв, показывает его один раз, преподаватель передаёт ученику. Почты для сброса по-прежнему нет.
- **Ученик видит свою неделю** на «Сегодня» тем же отчётом; чужой отчёт недоступен ни ученику, ни преподавателю другой группы.

## Почему не так
- **Запросы к LRS из кабинета** — каждый экран зависел бы от доступности LRS и тянул бы сотни statement'ов ради счётчиков.
- **Оценка без сброса при перезагрузке** — преподаватель не узнал бы, что файл заменён после проверки.

## Последствия
- Ответы, отправленные до этой миграции, в кабинет не попадают (на пилоте их нет).
- Лимит попыток входа всё ещё нужен до открытого стенда (неделя 7).
